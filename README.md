# Apresentação do Projeto

**1. Nome do projeto:**

Pedra, Papel e Tesoura.

**2. Descrição do que o projeto faz:**

O projeto consiste em um jogo interativo de Pedra, Papel e Tesoura, no qual o usuário disputa contra o computador.

O jogador pode escolher entre três opções: pedra, papel ou tesoura. Após a escolha, o computador seleciona aleatoriamente uma jogada e o sistema verifica quem venceu a rodada.

O jogo apresenta:
- Placar de vitórias do jogador e do computador.
- Exibição das escolhas de ambos.
- Mensagem indicando vitória, derrota ou empate.
- Botão para reiniciar a partida.
- Interface visual moderna e adaptável a diferentes tamanhos de tela.

**3. Tecnologias utilizadas:**

- HTML5: utilizado para estruturar os elementos do jogo.
- CSS3: utilizado para criar o visual, as cores, os efeitos e a responsividade da página.
- JavaScript: utilizado para desenvolver a lógica do jogo, gerar escolhas aleatórias para o computador, verificar os resultados e atualizar o placar.

**4. Orientações de como executar ou visualizar o projeto:**

1. Baixe os três arquivos do projeto: `index.html`, `style.css` e `script.js`.
2. Coloque todos os arquivos dentro da mesma pasta.
3. Abra o arquivo `index.html` em um navegador, como Google Chrome, Microsoft Edge ou Firefox.
4. Escolha entre Pedra, Papel ou Tesoura para começar a jogar.
5. Utilize o botão "Reiniciar jogo" para zerar o placar e começar novamente.

Não é necessário instalar programas adicionais ou utilizar servidores para executar o projeto.
